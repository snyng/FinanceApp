# 云端智能记账与资产管理App

## 项目简介
本项目是一个移动端记账应用程序。系统包含完整的移动端UI交互与云端持久化数据库，支持收支明细记录、数据实时统计与云端同步。

## 核心功能
支持对“收入”与“支出”进行结构化记录，包含金额、分类、备注及时间戳。
采用 Serverless 架构，移动端通过RESTful API与云端SQLite数据库实时交互。
采用悬浮按钮与底部滑出模态框，实现现代化的移动端交互体验。


## 项目结构
为了保证代码的清晰与可维护性，项目文件结构划分如下：
*   `/frontend` - 包含移动端应用程序的所有源代码（UI视图、网络请求逻辑、状态管理）。
*   `/backend` - 包含云端服务器的API路由逻辑与数据库初始化、查询操作代码。
